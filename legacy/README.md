# 🚀 IDEALAUNCH

**Discover Ideas. Build the Future.**

IDEALAUNCH is a responsive Startup Ideas Discovery Platform built using only semantic HTML5, CSS3 and vanilla JavaScript.

## Features
- Session-based login using `sessionStorage`
- Login validation
- Protected application pages
- Logout
- Dashboard
- Startup idea listing
- Search and category filtering
- Sort by popularity/name
- Favourite/saved ideas using `localStorage`
- Idea details
- User profile
- Responsive UI
- Red/black premium UI theme

## JavaScript Concepts
- Arrays & Objects
- Functions
- `map()`
- `filter()`
- `find()`
- DOM manipulation
- Events
- Forms and validation
- `sessionStorage`
- `localStorage`

## Pages
1. Login — `index.html`
2. Dashboard — `dashboard.html`
3. Explore Ideas — `explore.html`
4. Saved Ideas — `saved.html`
5. Idea Details — `details.html`
6. Profile — `profile.html`

## Run
Open `index.html` with VS Code Live Server.

## Deploy to Netlify
Upload the project folder to Netlify or connect the GitHub repository. No backend or database is required.

## UI Style
**Dark Red Futuristic / Minimal Premium** — the same visual language is used throughout the platform.
